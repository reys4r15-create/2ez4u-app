# 2EZ4U APP - Delivery Service Engine

Proyek Akhir Mata Kuliah Struktur Data & Analisa Algoritma (EC234303)
Teknik Komputer - Institut Teknologi Sepuluh Nopember

## 📌 Deskripsi Proyek
2EZ4U APP adalah engine backend untuk aplikasi delivery service (seperti GoFood/GrabFood mini) yang dikembangkan tanpa menggunakan library struktur data bawaan Python (seperti dict, set, heapq, .sort()).

## 🛠️ Struktur Repositori
- `data/`: Berisi dataset `pesanan.csv` (200.000 data) dan `peta.csv`.
- `backend/`: 
  - `m1_pesanan.py`: Implementasi Custom Array dan Custom Linked List.
  - `m2_antrean.py`: Implementasi Circular Queue dan Stack (Undo).
  - `m3_laporan.py`: Algoritma Insertion Sort dan Binary Search.
- `app.py`: Antarmuka desktop GUI berbasis Tkinter.
